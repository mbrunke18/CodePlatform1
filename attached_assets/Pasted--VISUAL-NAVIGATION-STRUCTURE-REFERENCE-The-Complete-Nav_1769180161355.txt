## ✨ Key Design Principles

### **1. Phase Spine**
- Navigation IS the IDEA framework
- Customers learn framework by navigating
- Each phase groups related functions

### **2. Progressive Disclosure**
- Click phase → Expand to 6 items
- Don't overwhelm with all options
- Show what's relevant now

### **3. Visual Hierarchy**
- Emoji icons for quick scanning
- Gradient colors distinguish phases
- Descriptions for clarity

### **4. Consistent Patterns**
- Each page has same structure
- Headers, descriptions, content areas
- Easy to add real functionality

### **5. Self-Documenting**
- Navigation teaches IDEA framework
- Phase descriptions explain purpose
- No separate training needed
