### **Step 3: Update your Layout Component**

Find where you render the navigation (usually in a layout or App component):

**OLD CODE:**
```tsx
import StandardNav from '@/components/layout/StandardNav';

export default function App() {
  return (
    <div>
      <StandardNav />
      <main>{/* page content */}</main>
    </div>
  );
}
```

**NEW CODE:**
```tsx
import IDEASidebar from '@/components/layout/IDEASidebar';

export default function App() {
  return (
    <div className="flex">
      <IDEASidebar />
      <main className="flex-1">{/* page content */}</main>
    </div>
  );
}
```

## 🛠️ Customization Options

### Change Phase Colors
Edit `IDEASidebar.tsx` and update the color classes:
```tsx
{
  id: 'identify',
  color: 'from-blue-600 to-cyan-600',  // ← Change these
  ...
}
```

### Change Icons
Edit the emoji icons in `config.ts`:
```typescript
icon: '🎯',  // Change to any emoji
```

### Change Sidebar Width
Edit `IDEASidebar.tsx`:
```tsx
<aside className="w-72 ...">  {/* Change w-72 to w-80, w-64, etc */}
```
