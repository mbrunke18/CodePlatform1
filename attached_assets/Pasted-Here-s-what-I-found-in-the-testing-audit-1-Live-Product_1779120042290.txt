Global fix first (applies to ~10 of 13)
Most failures are from bodyText === "" (hydration timing), not broken pages.

Use one helper in both specs:

async function getStableBodyText(page: Page, minLen = 80) {
  await page.waitForLoadState('load');
  await expect.poll(
    async () => (await page.locator('body').innerText()).trim().length,
    { timeout: 15000, intervals: [250, 500, 1000] }
  ).toBeGreaterThan(minLen);
  return await page.locator('body').innerText();
}
Then replace raw innerText() reads with await getStableBodyText(page).
