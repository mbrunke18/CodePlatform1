# Readiness OS: Contextual Value Messaging Specification

## Overview

This document specifies contextual value messages ("Value Insights") that appear throughout the Readiness OS product experience. Each message anchors the user action, translates it to business value, and reinforces ROI in real-time.

**Design Principles:**
- Toast notifications (bottom-right), not modal pop-ups
- Dismissible with "X" or auto-fade after 8 seconds
- Subtle animation on appear (slide up + fade in)
- User setting: "Show Value Insights" toggle (on by default for first 90 days)
- Aggregate data feeds into Value Dashboard

---

## PHASE 1: IDENTIFY (Trigger Detection)

```

┌──────────────────────────────────┐

└──────────────────────────────────┘
```
