# STEP 3: Update Your Layout

## Find and Replace Your Navigation Component

### Find This (Old Code):
```tsx
import StandardNav from '@/components/layout/StandardNav';
// or whatever your old nav component was called

export default function App() {
  return (
    <div>
      <StandardNav />
      <main>{/* page content */}</main>
    </div>
  );
}
```

### Replace With This (New Code):
```tsx
import IDEASidebar from '@/components/layout/IDEASidebar';

export default function App() {
  return (
    <div className="flex">
      <IDEASidebar />
      <main className="flex-1">{/* page content */}</main>
    </div>
  );
}
```

**Key changes:**
- Replace old nav import with `import IDEASidebar from '@/components/layout/IDEASidebar'`
- Add `className="flex"` to parent container
- Replace old nav component with `<IDEASidebar />`
- Add `className="flex-1"` to main content area so it takes remaining space

# Troubleshooting

## Problem: Sidebar not showing

**Solution 1: Check imports**
- Make sure you imported IDEASidebar
- Check file path is correct: `@/components/layout/IDEASidebar`

**Solution 2: Check layout structure**
- Parent div needs `className="flex"`
- Main content needs `className="flex-1"`

**Solution 3: Check Tailwind**
- Make sure Tailwind CSS is installed and working
- Clear browser cache: Ctrl+Shift+Delete

## Problem: Routes not working

**Solution 1: Check route syntax**
- Make sure you're using `element={<ComponentName />}` (React Router v6+)
- NOT `component={ComponentName}` (that's React Router v5)

**Solution 2: Check imports**
- Verify all component imports are present at top of file
- Check spelling matches (case-sensitive)

**Solution 3: Check paths**
- Path should start with `/` like `/identify/playbooks`
- Not `identify/playbooks` (without slash)

## Problem: Styling looks weird

**Solution 1: Tailwind not working**
- Make sure Tailwind CSS is configured
- Check that `@/` path alias works (should be in tsconfig.json)

**Solution 2: Dark mode issue**
- Some IDEASidebar styles assume dark mode
- Check if your app uses dark mode classes
- Add `className="dark"` to parent if needed

## Problem: "Cannot find module" error

**Solution 1: Check folder structure**
- Make sure folders exist: `client/src/pages/identify/`, `client/src/pages/detect/`, etc.
- Or adjust import paths to match your structure

**Solution 2: Check path alias**
- Make sure `@/` is mapped in tsconfig.json to `./src/`

**Solution 3: Restart dev server**
- Stop and restart `npm run dev`
- Sometimes path resolution needs a restart

## Problem: Sidebar collapses/expands weirdly

**This is normal!** - Click a phase header to toggle expansion.
