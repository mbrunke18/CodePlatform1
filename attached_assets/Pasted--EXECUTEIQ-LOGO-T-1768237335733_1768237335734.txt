================================================================================
TROUBLESHOOTING
================================================================================

PROBLEM: Logo doesn't render (blank space)
FIX: 
  - Verify ExecuteIQLogo.tsx exists in /src/components/
  - Check import: import ExecuteIQLogo from '@/components/ExecuteIQLogo'
  - Look in browser console for errors

PROBLEM: Colors don't show (looks gray/different)
FIX:
  - Verify CSS variables in globals.css :root { }
  - Verify fonts loaded (check DevTools → Network)
  - Clear browser cache (Ctrl+Shift+Delete)

PROBLEM: Old M logo still showing
FIX:
  - Search for "MIcon" or "m-icon" in codebase
  - Replace all instances with ExecuteIQLogo
  - Remove old import statements

PROBLEM: "Execute Decisions at Scale" tagline missing
FIX:
  - Verify ExecuteIQLogo has showTagline={true}
  - Check variant is "full" not "icon-only"
  - Verify CSS variables include executeiq-gold color

PROBLEM: Component not found error
FIX:
  - Restart Replit after creating ExecuteIQLogo.tsx
  - Verify file path: /src/components/ExecuteIQLogo.tsx
  - Check for typos in import statement
