EXECUTIVE SUMMARY
-----------------
M is the Strategic Execution Operating System for Fortune 1000 companies. We cut 
enterprise response time from 72 hours to 12 minutes by activating pre-staged 
playbooks when strategic events occur.

Core Value Proposition: "Adapt at the Speed of Change"

The Problem We Solve:
- Organizations lose 20-50 hours getting coordinated after strategic events
- 87% of strategic initiatives fail due to poor execution
- AI made individual work 10X faster, but coordination speed hasn't changed


================================================================================
                          PART 1: THE IDEA FRAMEWORK
================================================================================

M operates on the IDEA Framework - a human-AI partnership model with four phases:

------------------------------------------------------------------------------
PHASE 1: IDENTIFY - Build Your Playbook Library
------------------------------------------------------------------------------
Description: Map your operating model to execution playbooks. Pre-stage responses 
across 9 strategic domains. Know who does what before anything happens.

Capabilities:
  - Operating Model Alignment diagnostic
  - 166 pre-built playbooks ready to deploy
  - Stakeholder accountability mapping
  - Readiness scoring and gap analysis

Key Metrics:
  - Primary: Playbooks Staged
  - Secondary: Stakeholders Mapped
  - Target: 100% coverage across 9 domains

Features:
  - Playbook template library with industry-specific variants
  - Drag-and-drop stakeholder assignment
  - Role-based task allocation
  - Approval workflow configuration
  - Budget pre-authorization setup
  - SLA and escalation path definition

------------------------------------------------------------------------------
PHASE 2: DETECT - Monitor Signals
------------------------------------------------------------------------------
Description: AI-powered monitoring spots signals early. Real-time triggers across 
market, competitive, and regulatory landscapes. Intelligence reports, not surprises.

Capabilities:
  - AI pattern recognition across 10,000+ scenarios
  - Competitive intelligence monitoring
  - Early warning trigger system
  - Market signal aggregation

Key Metrics:
  - Primary: Signals Detected
  - Secondary: Avg Detection Lead Time
  - Target: < 5 min from signal to alert

Features:
  - Multi-source intelligence aggregation
  - Configurable trigger conditions with AND/OR logic
  - Confidence scoring for detected signals
  - Alert prioritization (opportunity, risk, competitive threat, market shift, regulatory change)
  - Real-time dashboard with signal feed
  - Custom monitoring rules per domain

------------------------------------------------------------------------------
PHASE 3: EXECUTE - Coordinate Response
------------------------------------------------------------------------------
Description: Coordinated action in 12 minutes vs. 72-hour industry average. 
Everyone aligned, nothing lost in translation.

Capabilities:
  - Automated stakeholder routing
  - Real-time execution tracking
  - Rapid Response mode for urgent scenarios
  - Mid-execution adjustments and pivots

Key Metrics:
  - Primary: Avg Response Time
  - Secondary: Stakeholder Alignment Rate
  - Target: 12 min coordination start

Features:
  - Command Center with live execution timeline
  - Three-phase execution model:
    * IMMEDIATE (0-2 minutes): Critical notifications, key stakeholder alerts
    * SECONDARY (2-5 minutes): Task deployment, resource allocation
    * FOLLOW-UP (5-12 minutes): Full coordination, document staging
  - Stakeholder acknowledgment tracking
  - Real-time progress visualization
  - Escalation automation when SLAs breach
  - In-flight plan modifications

------------------------------------------------------------------------------
PHASE 4: ADVANCE - Capture Learning
------------------------------------------------------------------------------
Description: Every execution makes you stronger. Automated retrospectives capture 
what worked. Institutional knowledge compounds, not walks out the door.

Capabilities:
  - Post-action analysis and debrief
  - Playbook refinement recommendations
  - Performance benchmarking
  - Institutional learning capture

Key Metrics:
  - Primary: Lessons Captured
  - Secondary: Playbook Improvements
  - Target: Continuous improvement loop

Features:
  - Automated debrief scheduling
  - Outcome classification (successful, partially successful, failed, cancelled)
  - AI-powered root cause analysis
  - Playbook version control with change history
  - Lessons learned database with search
  - Effectiveness scoring and trend analysis

FRONTEND STACK

  Styling:       Tailwind CSS with custom design system
  State:         TanStack Query v5 (server state)
  Forms:         React Hook Form with Zod validation
  Routing:       Wouter (lightweight client-side routing)
  Charts:        Recharts for data visualization
  Icons:         Lucide React
  Animation:     Framer Motion

Design System:
  - 60+ utility classes
  - Full dark/light mode support
  - WCAG AAA contrast compliance
  - Mobile-responsive layouts

------------------------------------------------------------------------------
BACKEND STACK
------------------------------------------------------------------------------
  Runtime:       Node.js
  Framework:     Express.js with TypeScript
  ORM:           Drizzle ORM (type-safe SQL)
  Validation:    Zod + drizzle-zod
  Logging:       Pino (structured JSON logs)
  
API Features:
  - RESTful endpoints
  - Request validation middleware
  - Error handling with consistent response format
  - Audit logging for all operations

------------------------------------------------------------------------------
DATABASE
------------------------------------------------------------------------------
  Database:      PostgreSQL (Neon serverless)
  ORM:           Drizzle ORM
  Migrations:    Schema push (npm run db:push)
  Session Store: PostgreSQL-backed sessions

Schema Highlights:
  - 40+ tables for full enterprise functionality
  - UUID primary keys for distributed safety
  - JSONB columns for flexible metadata
  - PostgreSQL enums for data integrity
  - Proper indexing for query performance
  - Relations with cascade delete where appropriate

Key Entities:
  - users (enterprise user management)
  - organizations (multi-tenant support)
  - businessUnits (hierarchical structure)
  - strategicScenarios (playbooks)
  - scenarioExecutionPlans (execution templates)
  - executionInstances (active executions)
  - triggers (signal definitions)
  - alerts (detected signals)
  - tasks (work items)
  - stakeholderMappings (role assignments)
  - lessonsLearned (institutional knowledge)

AUTHENTICATION & SECURITY
------------------------------------------------------------------------------
Authentication:
  - Replit OIDC integration
  - Passport.js with session management
  - PostgreSQL session store
  - HTTP-only, secure cookies

Security Headers (Helmet):
  - Content Security Policy (CSP)
  - XSS protection
  - Frame guards (clickjacking prevention)
  - HSTS (HTTP Strict Transport Security)

Rate Limiting:
  - General API: 1000 requests per 15 minutes

Data Protection:
