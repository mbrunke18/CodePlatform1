## FEATURE 2: PLAYBOOK GENERATOR (AI-Powered)

After analysis, generate a complete playbook from their incident:

**Output:**
- Playbook name (e.g., "Ransomware Response — Multi-Site Protocol")
- Playbook code (e.g., #SEC-001)
- 4-6 trigger conditions specific to their scenario
- Stakeholder roles with RACI assignments
- 6-8 tasks with owners and priorities
- 3-4 pre-authorized decision thresholds

**Make it editable:**
- User can modify triggers, tasks, roles
- User can add their actual team members (name, role, email)
- User can adjust thresholds
