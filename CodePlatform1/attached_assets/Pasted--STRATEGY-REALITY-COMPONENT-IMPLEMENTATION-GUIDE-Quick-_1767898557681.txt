# STRATEGY REALITY COMPONENT - IMPLEMENTATION GUIDE

## Quick Start

### Step 1: Copy the Component File

Copy `StrategyReality.tsx` to your Replit project:

```
client/src/components/marketing/StrategyReality.tsx
```

Or if you don't have a `marketing` folder, create one or put it in `components/`:

```
client/src/components/StrategyReality.tsx
```

---

### Step 2: Check Dependencies

The component uses these packages (you likely already have them):

```bash
# Check if you have framer-motion
npm list framer-motion

# If not installed:
npm install framer-motion
```

Also uses:
- `lucide-react` (icons) - you likely have this
- Tailwind CSS - you have this

---

### Step 3: Import Where Needed

#### Option A: Add to Landing Page / Home

In your main landing page file (e.g., `client/src/pages/Home.tsx` or `client/src/pages/Landing.tsx`):

```tsx
import { StrategyReality, StrategyRealityHero, StrategyToIDEA } from "@/components/marketing/StrategyReality";

export default function Home() {
  return (
    <div>
      {/* Your existing hero section OR use the new one */}
      <StrategyRealityHero />
      
      {/* The main visualization */}
      <StrategyReality />
      
      {/* IDEA framework mapping */}
      <StrategyToIDEA />
      
      {/* Rest of your page... */}
    </div>
  );
}
```

#### Option B: Create a New "Why M Platform" Page

Create `client/src/pages/WhyMPlatform.tsx`:

```tsx
import StrategyRealityPage from "@/components/marketing/StrategyReality";

export default function WhyMPlatform() {
  return <StrategyRealityPage />;
}
```

Then add the route (in your routing config):

```tsx
<Route path="/why" component={WhyMPlatform} />
```

#### Option C: Add Compact Version to Sidebar

```tsx
import { StrategyRealityCompact } from "@/components/marketing/StrategyReality";

// In any component/page:
<StrategyRealityCompact />
```

## Component Options

The file includes 5 components you can use:

| Component | Use Case | Size |
|-----------|----------|------|
| `StrategyRealityHero` | Full-page hero section | Large |
| `StrategyReality` | Main visualization with problem/solution | Medium |
| `StrategyToIDEA` | Maps 8 boxes → IDEA framework | Medium |
| `StrategyRealityCompact` | Sidebar or small space | Small |
| `StrategyRealityPage` | Full page (combines Hero + Reality + IDEA) | Full Page |

## Customization

### Change the CTA Button Link

Find this line and update the button:

```tsx
<button className="inline-flex items-center gap-2 bg-red-600 hover:bg-red-700...">
  See How M Platform Works
  <ArrowRight className="w-5 h-5" />
</button>
```

Change to a Link:

```tsx
import { Link } from "wouter";

<Link href="/demo">
  <a className="inline-flex items-center gap-2 bg-red-600 hover:bg-red-700 text-white font-semibold px-8 py-4 rounded-lg transition-colors">
    See How M Platform Works
    <ArrowRight className="w-5 h-5" />
  </a>
</Link>
```

### Adjust Colors

The component uses your existing color scheme:
- `bg-slate-950` - dark background
- `text-pink-500` - accent for "Strategy" 
- `text-red-500` / `text-emerald-500` - problem/solution
- `bg-red-600` - CTA buttons

These should match your existing M Platform design.

### Change Animation Speed

Adjust the `transition={{ delay: index * 0.1 }}` values:
- Faster: `delay: index * 0.05`
- Slower: `delay: index * 0.15`

## Troubleshooting

### "Cannot find module" Error

Make sure the import path matches where you put the file:

```tsx
// If in components/marketing/
import { StrategyReality } from "@/components/marketing/StrategyReality";

// If in components/
import { StrategyReality } from "@/components/StrategyReality";
```

### Framer Motion Not Working

Install it:
```bash
npm install framer-motion
```

### Animations Not Showing

Make sure you have `whileInView` support. If it's not working, you can remove the motion wrappers and use plain divs - the component will still work, just without animations.

Replace:
```tsx
<motion.div
  initial={{ opacity: 0, y: 20 }}
  whileInView={{ opacity: 1, y: 0 }}
  viewport={{ once: true }}
>
```

With:
```tsx
<div>
```
